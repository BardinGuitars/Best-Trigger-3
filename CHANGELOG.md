# Changelog · История изменений

## 0.2.13
- **Samples:** the project remembers which file each sample was; if a file is not the one the project was saved with, the plugin says so. · **Сэмплы:** проект запоминает, какой файл был у каждого сэмпла; если файл не тот, с которым проект сохранён, плагин сообщает об этом.
- **Spectrum:** new **Reset** button; the settings you choose are remembered. · **Spectrum:** новая кнопка **Reset**; выбранные настройки запоминаются.
- **Auto trim** is off by default. · **Auto trim** по умолчанию выключен.
- A **video** button in the quick start window opens our YouTube channel. · Кнопка **видео** в окне быстрого старта открывает наш канал на YouTube.

## 0.2.12
- **Spectrum** — a third view of the scope (frequency response of the output): speeds from *Very slow* to *Total*, Energy / RMS, Slope typed in by hand, 41 / 61 / Hi-res bands, vertical stretch with the arrows, drag with the middle mouse button; the settings are remembered. Each view has its own button. · **Spectrum** — третий вид осциллографа (АЧХ выхода): скорости от *Very slow* до *Total*, Energy / RMS, Slope вводится числом, 41 / 61 / Hi-res полос, растяжение по вертикали стрелками, перетаскивание средней кнопкой мыши; настройки запоминаются. У каждого вида своя кнопка.
- **Activity lights:** level meter beside the fader, name plate fill, layer and take; the Original has a meter too. Each can be switched off in the settings menu. · **Индикация:** индикатор уровня у фейдера, заливка плашки, слой и дубль; у Original тоже есть индикатор. Каждый пункт отключается в меню настроек.
- **Auto threshold** is more accurate; Auto also sets Sensitivity. · **Auto threshold** стал точнее; Auto ещё и выставляет Sensitivity.
- **Remember last samples / settings** are off by default; the remembered samples no longer appear in other instances. · **Remember last samples / settings** по умолчанию выключены; запомненные сэмплы больше не попадают в другие экземпляры.
- Header: the logo opens the web site, the name opens *About*, the version opens the changelog. · Шапка: логотип открывает сайт, название — *About*, версия — список изменений.

## 0.2.11
- **Separate outputs** (full version): Original and Smp 1 … Smp 6 on their own stereo outputs; the **OUT** button on a channel sends it there. In REAPER: right-click the plugin → *Build multichannel routing*. · **Отдельные выходы** (полная версия): Original и Smp 1 … Smp 6 на своих стерео-выходах; кнопка **OUT** на канале отправляет его туда. В REAPER: правый щелчок по плагину → *Build multichannel routing*.
- **For best sound** balances only the close microphones. · **For best sound** выравнивает только близкие микрофоны.
- The interface size is remembered; new sizes **75%** and **110%**. · Размер интерфейса запоминается; новые размеры **75%** и **110%**.
- **Hold** and **Phase** moved onto the scope; **Reset phase** and **Clear samples** are at the bottom of the right panel. · **Hold** и **Phase** переехали на осциллограф; **Reset phase** и **Clear samples** внизу правой панели.
- **Online libraries** update when a new version is published. The Artem Music library is fixed: stereo and all takes (version 1.1). · **Онлайн-библиотеки** обновляются, когда выходит новая версия. Библиотека Artem Music исправлена: стерео и все дубли (версия 1.1).

## 0.2.10
- **For best sound** (Auto → Level): sets the levels of the samples for a modern kick sound. · **For best sound** (Auto → Level): подбирает уровни сэмплов для современного звука кика.
- **Reset phase** and **Clear samples** buttons; **Clear all samples** in the browser. · Кнопки **Reset phase** и **Clear samples**; **Clear all samples** в браузере.
- Auto phase works better with the LEAD / FOL / ALIGN roles. · Auto phase лучше работает с ролями LEAD / FOL / ALIGN.
- The right panel is more compact. · Правая панель стала компактнее.

## 0.2.9
- Auto phase works with the LEAD / FOL / ALIGN roles. · Auto phase работает с ролями LEAD / FOL / ALIGN.
- Auto threshold copes with fast passages. · Auto threshold справляется с быстрыми пассажами.
- Auto Release does not cut a strong ring of a short hit. · Auto Release не обрывает сильный хвост короткого удара.
- Auto trim is on by default. · Auto trim включён по умолчанию.
