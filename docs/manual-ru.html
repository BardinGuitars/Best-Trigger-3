1. О плагине

Best Trigger 3 — барабанный триггер. Он находит каждый удар на записанной дорожке бочки, малого или тома и играет ваши сэмплы вместо оригинала или вместе с ним.

  • До шести сэмплов одновременно, у каждого свои уровень, панорама, тон, огибающая, фильтры, Mute/Solo и переворот фазы.
  • Мультисэмплы: слои по силе удара и несколько дублей, формат .bt3.
  • Осциллограф: порог, Retrigger и сдвиги сэмплов перетаскиваются мышью.
  • Инструменты фазы и Full Auto.
  • A | B, Undo/Redo, пресеты, браузер сэмплов, MIDI на входе и выходе.

3. Установка

Windows

  1. Скачайте установщик на странице Releases и запустите. Если Windows показывает синее предупреждение, нажмите Подробнее → Выполнить в любом случае.
  2. Перед установкой закройте DAW, после — пересканируйте плагины.
  3. Вставьте плагин на дорожку с барабаном как эффект.

macOS

При первом запуске macOS предупредит: см. как разрешить плагин.

4. Быстрый старт

  1. Чтобы слышать и оригинал, поднимите фейдер Original до 0 дБ.
  2. Загрузите сэмплы. Free: они уже стоят. Полная: перетащите файл на плашку, щёлкните плашку правой кнопкой или откройте Browser. Щелчок по плашке играет сэмпл (правее — сильнее).
  3. Запустите воспроизведение и выберите Auto → Full Auto.

Shift делает любую ручку и фейдер в десять раз точнее. Двойной щелчок возвращает значение по умолчанию; правый щелчок по ручке — ввести число.

Пресеты

Пресет хранит все настройки и загруженные сэмплы. Кнопка Presets открывает список; доступны Save, Save as…, Delete и Initialize (настройки по умолчанию). Стрелки листают пресеты, а Undo отменяет загрузку пресета. В бесплатной версии пресет хранит только настройки.

6. Распознавание ударов

Настраивается на осциллографе в виде Timeline. Двойной щелчок по окошку значения — ввести число.

ПараметрСмыслПо умолч.
ThresholdУровень, выше которого сигнал считается ударом. Тяните красные линии.−30 дБ
SensitivityКак быстро детектор готов к следующему удару. Больше — надёжнее против двойных, меньше — ловит быстрые удары. Тяните жёлтые линии.50%
Retrigger«Мёртвое время» после удара. Тяните край фиолетовой зоны.40 мс
InputУровень ваших самых сильных ударов: они играют самым сильным слоем. Ставит Full Auto; или тяните зелёную линию Loud.0 дБ
Low Cut / High CutФильтры только для детектора; звук не меняется.—

Dynamics: 1.00 — сила удара полностью управляет слоем и громкостью; 0 — всегда самый сильный слой на полной громкости.

  1. Запустите воспроизведение; колесо меняет окно времени, Hold замораживает картинку; высота подбирается сама.
  2. Подвиньте красные линии так, чтобы настоящие удары их пересекали, а лишние звуки оставались ниже.
  3. Крестики — звуки, пропущенные из-за Retrigger. Зачёркнуты настоящие удары: уменьшите Retrigger или Sensitivity. Несколько линий на одном ударе: увеличьте их.
СоветЕсли в дорожку сильно попадают другие барабаны, поставьте гейт перед Best Trigger.

7. Сэмплы и микшер

На каждый удар играют сразу все загруженные сэмплы.

  • Полная версия: перетащите файл на плашку или щёлкните плашку правой кнопкой: Load sample or .bt3 file…, Load folder (multisample)…, Save multisample file (.bt3)…, Clear sample. WAV, AIFF, FLAC.
  • Бесплатная версия: на плашках встроенные сэмплы; правый щелчок — Restore the original sample.
  • Щелчок по плашке играет только этот сэмпл со всеми его настройками; правее — сильнее.

8. Мультисэмплы

В мультисэмпле есть слои по силе удара и несколько дублей. Загрузка папки: правый щелчок по плашке → Load folder (multisample)…. Называйте файлы так: Name_R1_V0.wav (подойдёт и Name_V0_R1.wav):

  • R + число: номер дубля.
  • V + число: скорость (0–127), с которой играет слой, например _V0, _V50, _V105.
  • Малые числа (_V1 … _V4) распределяются равномерно; плагин сам определяет по записям, где самый сильный удар, поэтому неважно, какой номер сильнейший.

Сохранить мультисэмпл одним файлом .bt3: правый щелчок по плашке → Save multisample file (.bt3)….

9. Библиотека и браузер

Только полная версия.

  • Папка библиотеки: шестерёнка → Sample library. По умолчанию Documents\SSM-Audio\Best Trigger 3\Library.
  • Browser (правая панель): дерево библиотеки с поиском и Audition. Щелчок играет файл; двойной щелчок загружает его в первый свободный канал; можно перетащить на пэд. Правый щелчок по файлу — ещё действия, по пэду — очистить.
  • Remember place (слева внизу): браузер открывается там, где вы остановились. Файлы WAV и BT3 отмечены разными цветами.
  • Online libraries…: бесплатные библиотеки с обложкой и текстом автора. Выберите и нажмите Download and install.
  • Migration…: превращает библиотеку .tci в файлы .bt3. Выберите папку; файлы появятся в вашей библиотеке. Конвертируйте только бесплатные или свои сэмплы.

10. Фаза

Рядом с именем каждого сэмпла есть кнопка роли: LEAD (выравнивается по оригиналу; первый LEAD — ведущий), FOL (двигается вместе с ведущим: рум и оверхеды) и ALIGN (сам находит сдвиг и полярность относительно ведущего, без музыки: Out, Sub). Сэмплы одного набора играют один и тот же дубль на каждом ударе.

Сэмпл вместе с оригиналом может «истончить» звук, если их волны гасят друг друга. Переключите кнопку на правой панели на Phase, чтобы увидеть последний удар: оригинал, сэмплы и их сумму.

  1. Щёлкните окошко Smp вверху осциллографа и тяните график влево или вправо: так меняется Offset сэмпла (±30 мс; Shift — точнее, двойной щелчок по графику — 0).
  2. Если первые волны идут в противоположные стороны, нажмите Ø.
  3. Следите за Sum gain: зелёный (от +1,5 дБ) — хорошо, красный (ниже −1,5 дБ) — каналы гасят друг друга.

Auto → Track phase on every hit подстраивает начало каждого сэмпла до ±2 мс. Лучше всего работает на чистой дорожке.

11. Меню Auto

Пока инструмент слушает музыку, кнопка Auto мигает. Любой результат можно отменить кнопкой Undo.

ПунктЧто делает
Full AutoСтавит Threshold и Retrigger, выравнивает фазу каждого сэмпла и включает слежение за фазой.
Whole signal / BassЧасть сигнала для анализа. Bass — для бочки, Whole signal — для малого.
Align phaseНаходит Offset и Ø каждого сэмпла.
Track phase on every hitВключает или выключает слежение за фазой.
Match samples to the originalПодбирает уровни сэмплов по громкости оригинала.
Make samples equally loudВыравнивает сэмплы; музыка не нужна.
Learn Threshold and RetriggerСтавит только эти два параметра.
Start playback automaticallyРаботает не во всех DAW.

Инструментам нужен звук: запустите воспроизведение.

12. MIDI

  • Выход: каждый удар отправляется ещё и MIDI-нотой (шестерёнка → MIDI out note).
  • Запись: нажмите REC MIDI, сыграйте, нажмите ещё раз, затем перетащите зелёную ручку drag MIDI clip to DAW на MIDI-дорожку.
  • Вход: шестерёнка → Trigger source → MIDI и нота MIDI in note; скорость ноты задаёт силу удара.
