1. About

Best Trigger 3 is a drum trigger. It finds every hit on a recorded kick, snare or tom track and plays your samples instead of the original or together with it.

  • Up to six samples at once, each with level, pan, tune, envelope, filters, Mute/Solo and phase flip.
  • Multisamples: velocity layers and round-robin takes, the .bt3 format.
  • An oscilloscope with a draggable threshold, Retrigger and sample Offsets.
  • Phase tools and Full Auto.
  • A | B, Undo/Redo, presets, a sample browser, MIDI in and out.

3. Installation

Windows

  1. Download the installer from Releases and run it. If Windows shows a blue warning, click More info → Run anyway.
  2. Close your DAW first and rescan plugins afterwards.
  3. Insert the plugin on a drum track as an effect.

macOS

macOS warns you the first time: see how to allow the plugin.

4. Quick start

  1. To hear the original too, raise the Original fader to 0 dB.
  2. Put samples in. Free: they are already there. Full: drop a file on a plate, right-click the plate, or open the Browser. A click on a plate plays it (further right = harder).
  3. Start playback and choose Auto → Full Auto.

Presets

A preset stores all settings and loaded samples. The Presets button opens the list; use Save, Save as…, Delete and Initialize (default settings). The arrows step through presets, and Undo takes a loaded preset back. In the free version a preset keeps the settings only.

6. Hit detection

Set these on the scope in the Timeline view. A double-click on a value box lets you type a number.

ParameterMeaningDefault
ThresholdThe level above which the signal is a hit. Drag the red lines.−30 dB
SensitivityHow quickly the detector is ready again. Higher = safer against doubles, lower = catches fast hits. Drag the yellow lines.50%
RetriggerThe dead time after a hit. Drag the edge of the purple zone.40 ms
InputThe level of your loudest hits: they play the hardest layer. Full Auto sets it; or drag the green Loud line.0 dB
Low Cut / High CutFilters for the detector only; the sound does not change.—

Dynamics: 1.00 = the hit strength fully controls the layer and loudness; 0 = always the hardest layer at full level.

  1. Start playback; the wheel zooms the time window, Hold freezes the picture; the height fits itself.
  2. Drag the red lines so that real hits cross them and unwanted sounds stay below.
  3. Crosses mark sounds skipped by Retrigger. Real hits crossed out: lower Retrigger or Sensitivity. Several lines on one hit: raise them.
TipWith a lot of bleed from other drums, put a gate before Best Trigger.

7. Samples and mixer

On every hit all loaded samples play at once.

  • Full version: drop a file on a plate, or right-click the plate: Load sample or .bt3 file…, Load folder (multisample)…, Save multisample file (.bt3)…, Copy sample name (name and extension, to the clipboard), Clear sample. WAV, AIFF, FLAC.
  • Free version: the plates hold built-in samples; right-click offers Restore the original sample.
  • A click on a plate plays only that sample with all its settings; further right = harder.

8. Multisamples

A multisample has velocity layers and several round-robin takes. Load a folder: right-click a plate → Load folder (multisample)…. Name the files like Name_R1_V0.wav (Name_V0_R1.wav works too):

  • R + number: the take.
  • V + number: the velocity (0–127) from which the layer plays, e.g. _V0, _V50, _V105.
  • Small numbers (_V1 … _V4) are spread evenly; the plugin checks which end is the loudest recording, so it does not matter which number is the hardest hit.

To save a multisample as one .bt3 file: right-click the plate → Save multisample file (.bt3)….

9. Library and browser

Full version only.

  • Library folder: gear → Sample library. By default Documents\SSM-Audio\Best Trigger 3\Library.
  • Browser (right panel): a tree of your library with search and Audition. A click plays a file; a double-click loads it into the next free channel; you can also drag onto a pad. Right-click a file for more, right-click a pad to clear it. A sound file can also be dragged from the browser straight into the DAW.
  • Remember place (bottom left): the browser opens where you stopped. WAV and BT3 files have different icon colours.
  • Online libraries…: free libraries with a cover and the author's text. Choose one and press Download and install.
  • Migration…: converts a .tci library into .bt3 files. Choose the folder; the files are created in your library. Convert only free samples or your own.

10. Phase

Next to each sample name is a role button: LEAD (lined up with the original; the first LEAD sample is the leader), FOL (moves together with the leader: rooms and overheads) and ALIGN (finds its own offset and polarity against the leader, without music: Out, Sub). Samples of one set also play the same take on every hit.

A sample played with the original can thin out the sound if their waves cancel. Switch the right-panel button to Phase to see the last hit: the original, the samples and their sum.

  1. Click a Smp box at the top of the scope and drag the graph left or right to move that sample's Offset (±30 ms; Shift = finer, double-click the graph = 0).
  2. If the first waves go in opposite directions, press Ø.
  3. Watch Sum gain: green (+1.5 dB or more) is good, red (below −1.5 dB) means the channels cancel.

Auto → Track phase on every hit fine-tunes the start of each sample by up to ±2 ms. It works best on a clean track.

11. Auto

While a tool listens to the music, the Auto button blinks. Every result can be undone with Undo.

ItemWhat it does
Full AutoSets Threshold, Retrigger, Sensitivity and Input and aligns the phase of each sample.
Whole signal / BassThe part of the signal used for the analysis. Bass for a kick, whole signal for a snare.
Align phaseFinds the Offset and Ø of each sample.
Track phase on every hitSwitches phase tracking on or off.
Match samples to the originalSets sample levels from the loudness of the original.
Make samples equally loudEvens out the samples; no music needed.
For best soundSets the levels of the samples for a modern kick sound (set the phase first).
Learn Threshold and RetriggerSets only the detector: Threshold, Retrigger, Sensitivity and Input.
Start playback automaticallyWorks only in some DAWs.

The tools need sound: start playback.

12. MIDI

  • Output: every hit is also sent as a MIDI note (gear → MIDI out note).
  • Recording: press REC MIDI, play, press it again, then drag the green drag MIDI clip to DAW handle onto a MIDI track.
  • Input: gear → Trigger source → MIDI and a MIDI in note; the velocity sets the hit strength.
