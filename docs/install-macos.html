macOS: allowing the plugin · как разрешить плагин

Manual (English) · Руководство (русский)

English

The installer will not open

  • Right-click the installer → Open → Open (once).
  • Or: System Settings → Privacy & Security → Open Anyway.

The DAW does not show the plugin

  • In Privacy & Security click Open Anyway next to the message about "Best Trigger 3", then rescan plugins.
  • No message? Paste in Terminal (Applications → Utilities):
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Best Trigger 3.vst3"

Free version: Best Trigger 3 Free.vst3. Restart the DAW and rescan.

Русский

Установщик не открывается

  • Правый щелчок по установщику → Открыть → Открыть (один раз).
  • Или: Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.

DAW не показывает плагин

  • В Конфиденциальность и безопасность нажмите Всё равно открыть у сообщения про «Best Trigger 3» и пересканируйте плагины.
  • Сообщения нет? Вставьте в Терминал (Программы → Утилиты):
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Best Trigger 3.vst3"

Бесплатная версия: Best Trigger 3 Free.vst3. Перезапустите DAW и пересканируйте.
